# The TEI subset

What Varians reads from and writes to TEI P5 (`packages/core/src/tei/`). Everything in the tables has a place in the stream model; elements outside them are read through (their text kept) with a warning, and never written.

**The ODD is normative.** What Varians writes is defined by the TEI customization [`varians.odd`](varians.odd) and the RelaxNG schema generated from it, [`varians.rng`](varians.rng) (see [BUILD.md](BUILD.md)); every `transcription.tei.xml` and `edition.tei.xml` must be valid against it. The customization is a pure restriction of TEI P5 4.12.0: a document valid against it is valid against tei_all. This page is the readable account of the same subset, and says how each element maps to the stream; where the two disagree, the ODD is right and this page is to be corrected. The reading side is wider than the writing side: the importer accepts any TEI and keeps what it can.

## Structure

| TEI                                                                                                                                                                                                 | In the stream                                                                                                | Notes                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<div type subtype n>`, `<div1>`…`<div7>`                                                                                                                                                           | an address part `{unit: subtype or type, n}` for segment starts                                              | divs of type `edition`, `translation`, `commentary`, `apparatus`, `transcription`, `notes`, `bibliography` without a subtype are containers and give no part |

| `<milestone unit n>`                                                                                                                                                                                | a segment start accumulating the latest `n` per unit (Stephanus page and section)                            | an earlier unit resets the later ones                                                                                                                        |

| `<cb n>`                                                                                                                                                                                            | a column break with a label                                                                                  |                                                                                                                                                              |
| `<p>`, `<ab>`                                                                                                                                                                                       | a paragraph break                                                                                            |                                                                                                                                                              |
| `<lg>`, `<item>`, `<row>`                                                                                                                                                                           | a line break                                                                                                 |                                                                                                                                                              |

## What a transcript keeps of an edition

A TEI document is read in one of two ways, chosen by whoever imports it (`importTei`, option `as`).

As **a text to start from** (`as: 'text'`) it gives its words and their numbering and nothing else: the word it prints where it gives a choice (the regularized, corrected or expanded one), its lines and paragraphs, and the numbered structure for the segments. Its marks, gaps, notes, figures and paratext are left behind, and its `<pb>` and `<cb>` are passed over as if not there: they are the pages of its own edition, not of the witness to be transcribed.

As **a transcript of the witness** (`as: 'transcript'`, the default) it is read with its features and its pages, as the rest of this document describes. A transcript holds its witness and nothing an editor added to it, so the elements by which the source's editor supplied or struck out are not kept as marks:

| TEI                                                        | In the stream                                                                                                                                                                                           |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<supplied reason="lost">`, and with `evidence="parallel"` | left out; the gap it fills is kept, as long as its letters: a gap object where whole words were supplied, a point mark `gap` in a word that keeps other letters. A `<gap>` inside it is counted with it |
| `<supplied reason="omitted">`                              | inside a word, letters of its normalized form only (`unchecked`); a whole word is left out                                                                                                              |
| `<surplus>`                                                | inside a word, letters of its diplomatic form only (`unchecked`); a whole word stays, unmarked                                                                                                          |
| `<choice><sic/><corr/></choice>`                           | the sic is the diplomatic form, the corr the normalized form (`unchecked`)                                                                                                                              |
| `<app type="editorial">`, `<app type="alternative">`       | the `<lem>`: the reading the source prints                                                                                                                                                              |
| `<num value/>` without letters, `<gap reason="omitted">`   | left out                                                                                                                                                                                                |

What Varians itself wrote is read back with `as: 'verbatim'`, which keeps every element as its mark, the marks `supplied`, `surplus` and `corr` of the table below among them; they belong to editions' texts.

A `<gap>` that touches the letters of a word, before, inside or after them, is a point mark of that word; one that touches none is an object. Collation does not read a word with such a mark: it counts with the gap.

## Leiden+

[Leiden+](https://papyri.info/docs/leiden_plus), the notation of papyri.info, is read by writing the EpiDoc each of its constructs stands for and reading that (`leidenPlusToEpiDoc`, `importLeidenPlus`), and a transcript is written as Leiden+ by `toLeidenPlus`: lines with their numbers, pages and columns as divisions, and every feature it has a way of saying. Segments, boxes and variants noted in the margin have none and are left out.

| any other `<app><lem/><rdg/></app>` on import                                | the lemma's words only, with a warning                                                                    | editions are written with `<app>`, see below                                                                                             |

A **correction** is a `del` or `add` mark (TEI `<del>`, `<add>`). Its `attrs.hand` names the hand that made it: a hand of the witness by id, written as `hand="#hand-ID"` pointing at the witness's `handNote`; `scribe` (the main hand, written as its handNote when one is registered, else left unsaid); `other` (an unidentified hand, left unsaid); or a value as imported, written as it came. Its `attrs.seq` is the stage of correction (TEI `@seq`): 1 for the first layer, 2 for the next; corrections without a stage belong to no particular layer. An edition can collate a witness as first written, after all corrections, after a stage, or with the corrections of one hand.

A **variant noted in the carrier** (a reading written in the margin or between the lines, often introduced by γρ., or elsewhere on the page) is the mark `variant` on each token of the words it concerns, all with the same `attrs.group`: `{ kind: 'variant', attrs: { group: 'k3f9', reading: 'ἔννεπε μοι', place: 'margin', hand: 'h2' } }`. It is always a whole-token mark, and a token has at most one. The span is written as one `<app>` whose `<lem>` holds the words as the text has them (with any breaks and marks inside) and whose single `<rdg>` holds the variant; the `<rdg>`'s `type` is the place. An edition may collate the variants as a text of their own under a sub-siglum (`A v.l.`): the words of each span are replaced by the reading, the rest of the witness as corrected.

## Writing

A transcription's text is written in `<body>` as one `<ab>`, or one `<p>` per paragraph when the stream has paragraph breaks, with breaks as `<lb/>`, `<cb/>` and `<pb/>` (`break="no"` after a token joined to the next; a text that ends in a joined token ends with `<lb break="no"/>`, which is read as the join and not as a line break, and a line break after that token is a second `<lb/>`), the start of each labelled segment as `<milestone unit="segment" n="LABEL"/>`, and, in the archive, every token as `<w xml:id="w-ID">` with `facs` pointing at its zones and a normalized form that differs as `<choice><orig>…</orig><reg>…</reg></choice>`. Marks are written as the elements of the table above, nested where their ranges nest and split where they overlap; a mark kind without an element of its own (`crux`, a note over a range) is `<seg type="KIND">`. Attributes of the XML namespace that an imported feature had (`xml:lang`) are written back with their prefix.

TEI allows no `<head>`, `<speaker>`, `<trailer>` or similar block inside `<ab>` or `<p>`, so paratext of those kinds is written as `<label type="head">`, `<label type="speaker">` and so on, the paratext's own type as `subtype`; `<label>`, `<stage>` and `<fw>` stand as themselves with the paratext's type as `type`. The importer reads both forms back to the same object.

## Header

`<titleStmt>` with the title, and in an edition an `<editor>` for each editor; `<publicationStmt>` with `<authority>Varians</authority><availability><licence>` when the record has a licence, else a plain statement; `<profileDesc><langUsage><language ident>` and `xml:lang` on `<text>`. In `<sourceDesc>`, a transcription has `<msDesc>` and an edition `<listWit>`, and either may have `<bibl type="sources">` with the sources its maker states; a source description with nothing to say has a `<p>`.

`<msDesc>`: `msIdentifier` (settlement, repository, idno; when none of these is known, `msName` with the witness's name, or its siglum, since TEI's rule `msId_minimal` forbids an identifier that is empty or begins with the siglum; then `altIdentifier type="siglum"`), `head` (name), `msContents/summary` (description), `physDesc/objectDesc` with `form` codex, scroll or leaf and `supportDesc` (material, extent), `handDesc hands` with one `handNote` per hand (`xml:id="hand-ID"`, `n` the label, `scope` sole, major or minor; the scribe of the text is sole or major), `history/origin/origDate`.

## Facsimile

Written: `<facsimile><surface xml:id n><graphic url width height/><zone xml:id ulx uly lrx lry|points/></surface></facsimile>`, with `<pb facs="#surface">` and `<w facs="#zone">` linking text to image. Coordinates are in pixels of the image when its size is known (`width` and `height` in `px`), else in thousandths of its width and height; a polygon, and a turned rectangle, are written as `points`. Zones are not read back from TEI yet; the archive's `zones.json` is the authoritative record.

## Editions

`exportEditionTei` writes the critical text with the parallel-segmentation apparatus: `<listWit>` from the conspectus (`<witness xml:id="wit-SIGLUM" n="SIGLUM">`, the siglum made a name: characters that cannot stand in one become `_`, and sigla that then coincide, such as A¹ and A², are told apart as `wit-A_` and `wit-A_-2`; no `<listWit>` when the conspectus is empty), the preface as `<front><div type="preface">`, `<body><div type="edition">` with one `<ab n="label">` per segment, and at every site `<app><lem wit="#wit-A #wit-C">…</lem><rdg wit="#wit-B">…</rdg></app>` (the base is left out of `wit`); an omission is an empty `<rdg wit/>`, a lacunose witness `<rdg wit><gap reason="lost"/></rdg>`, a conjecture `<rdg type="conjecture" resp="Name" source="…">`, an adopted conjecture `<lem resp="Name">`, a reported reading `<rdg type="reported">`, and a place where the witnesses have the same letters read otherwise `<app type="interpretative">`. Paratext is written as in a transcription (a marginal note of the edition as `<label type="margin">`), a paragraph break as `<lb/><lb/>`. Variants noted in a witness's carrier belong to the transcription and are not written in the edition's text.

## Restrictions of the ODD

Beyond the choice of elements, the ODD closes the values of a few attributes that have a fixed meaning here: `milestone/@unit` is `segment`; `app/@type` is `interpretative`; `rdg/@type` is `margin`, `interlinear` or `other` (a variant noted in the carrier) or `conjecture` or `reported` (in an edition); `objectDesc/@form` is `codex`, `scroll` or `leaf`; `altIdentifier/@type` is `siglum`. It documents the prefixes `tok`, `seg`, `wit`, `conj` and `person` for `<prefixDef>` without closing the list. Other attributes are as TEI defines them, since imported features keep theirs.

## What is not in TEI

Attested separators (`sep`), the `unchecked` flag, edition token sources, segment run parts, review marks and the change history live only in the JSON files of the archive.
